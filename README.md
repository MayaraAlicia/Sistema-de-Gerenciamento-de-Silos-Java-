# Sistema-de-Gerenciamento-de-Silos-Java-
Este foi meu primeiro projeto prático para iniciar os estudos em Java. O objetivo foi criar um sistema de console para gerenciar o estoque de grãos em silos.

O que eu pratiquei neste projeto:
* Lógica de programação e condicionais.
* Manipulação de Listas Dinâmicas (ArrayList).
* Tratamento de entrada de dados com Scanner.
* Transição de lógica procedural para Orientação a Objetos
